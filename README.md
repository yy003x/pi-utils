# pi-utils

个人使用的极简 Pi 扩展，只保留五项功能。适用于 Pi 1.4.x，唯一入口是 `utils/index.ts`。

## 五项功能

| 功能 | 内容 |
| --- | --- |
| 简洁状态栏 | 第一行显示原生风格路径和分支；第二行显示上下文、额度、运行统计、模型和思考级别；其它扩展状态集中在第三行 |
| 订阅额度 | 在状态栏自动显示当前官方 Codex OAuth 或 `zai-coding-cn` Coding Plan 的剩余比例、窗口和距重置时间；60 秒刷新 |
| API 费用 | 当前 Provider 为官方 `openai` API Key 渠道时自动查询该 Key 的费用；优先订阅起点，否则最近 7 天和 30 天；其他 Provider 不显示 |
| 轻量运行统计 | 当前或最近一次运行的耗时、工具调用次数、轮次、token 用量及结束状态；只留在内存 |
| `/cd` | 切换 Pi 会话工作目录，保留历史和当前分支；支持路径补全、相对路径、绝对路径和 `~` |

无需独立配置文件、布局预设或特殊字体。没有设置面板，不接管输入框，不增加工具、快捷键、队列、Shell、提醒或 AI 文案。

## 命令

```text
/stats              查看当前或最近一次运行统计
/cd                显示当前目录
/cd ../project     切换到指定目录
/cd "My Folder"    切换到含空格的目录
```

### 状态栏布局

第一行沿用原生 Pi 的路径和分支格式：完整工作目录，主目录及其子目录缩写为 `~`，Git 分支放在括号中；非 Git 目录不显示分支。第二行按上下文使用占比/窗口、额度、工具次数、token 总量、轮次、状态及耗时排列，渠道/模型和思考级别靠右，不重复目录和分支。第三行显示其它扩展状态。例如：

```text
~/.pi/agent/git/github.com/yy003x/pi-utils (main)
24.8%/512K 73%/1w/15h tools:8 token:126K turn:4 running:19m46s    openai-codex/gpt-6-astra high
Hermes：partial ⠸ review · 全局方案与单一执行 · 视角 1 (openai-codex/gpt-6-astra) ·
```

额度与 API 费用共用第二行上下文右侧的位置；API 费用存在时不再并列显示额度。除此之外，所有扩展通过 `setStatus()` 发布的状态均按键排序后合并到第三行，包括 Hermes、pi-review 和 pi-subagents；不按名称维护允许列表，前两行不混入外部状态。沿用 Pi 主题和列宽裁剪，内置标签不使用中文，外部状态保留原文。没有外部状态时不占第三行；Pi 重载会清空扩展状态，需等待相应扩展重新发布，不恢复旧状态。扩展自己的独立 widget 不由底栏接管。

上下文占用字段沿用原生 Pi 的主题配色：≤ 70% 为默认灰色，> 70% 且 ≤ 90% 为黄色（`warning`），> 90% 为红色（`error`）；未知占用保持灰色。阈值按未四舍五入的占用率判断，仅上下文字段变色，不影响额度或其它状态，也不弹出通知。

### 额度含义

额度的 `73%/1w/15h` 表示剩余 73%、周期一周、约 15 小时后重置，不是上下文占用。过期快照显示 `stale`，不会推算成满额；请求失败明确显示错误。

额度自动显示在状态栏，无需命令。Codex 百分比只代表主额度窗口，不包含模型专属限制、额外积分或其它 ChatGPT 用量；GLM 百分比代表套餐积分窗口，不是剩余 token 或金额。

只使用当前渠道的认证，不向代理地址或重定向地址发送凭据。请求合并去重，网络超时为 10 秒，快照保存在内存并绑定凭据指纹；切换模型、重载或退出时取消旧请求并清除旧状态。只在 TUI 会话查询，不对非交互子代理启动后台查询。

GLM 中国站监控接口不是公开稳定契约，可能随服务端变化。新版官方 OpenAI Responses OAuth 目前只显示订阅标识及用量入口，不借用 Codex 接口或本地 token 推算额度；其他渠道不显示额度。

### 当前 Provider 的 API 费用

无需命令。只在 TUI 且当前 Provider 为 `openai` 时自动处理；切换到 `openai-codex` 或其他 Provider 后立即清除费用显示。仅支持官方 `https://api.openai.com/v1` 的普通 API Key；同名代理或 OAuth 渠道显示不可查询，不混用凭据。

被统计的密钥直接取自宿主为当前模型解析的 Provider 认证，不另配 Key 或 Key ID。启动 Pi 的环境只需额外设置 `OPENAI_ADMIN_KEY`：目标 Key 所属组织的 **Admin API Key**，需要费用／用量、项目列表和项目 Key 元数据的读取权限，Read Only 即可。普通 Provider Key 不能替代它，也不要用 Admin Key 替换模型认证。不要把密钥写入会话或仓库。

扩展通过官方管理接口读取全部可见活跃项目及 Key 元数据，用当前密钥与脱敏值的前后缀匹配得到唯一 Key ID。脱敏匹配不是完整密钥验证；无匹配、多匹配、列表权限不足或分页失败时明确报错，不猜测目标，也不回退为组织合计。元数据只在内存处理，不显示项目名、账户信息或 Key ID。

费用只显示在第二行原来的订阅额度位置，例如 `0.0566$/7d 0.1234$/30d`，不占第三行、不加标题、时间戳或 `fallback`。有有效订阅起点时只显示 `1.2346$/17d`：N 为订阅起点至查询时覆盖的天数，不足一天向上取整，不是完整套餐周期；订阅区间和 7d/30d 不共存。金额保留四位小数。

启动和切换模型时查询，每分钟检查当前认证，账单请求限频五分钟；运行开始和结束也检查，合并进行中的请求。切换模型、会话、重载或退出时取消旧请求并清除旧状态。结果不弹通知、不写账本或会话条目；加载显示 `cost:...`，缺少凭据显示 `cost:auth`，不支持的认证或路由显示 `cost:n/a`，请求失败显示 `cost:err`。失败不冒充零费用，状态栏不展开长错误文案。

时间优先取已登录官方 `openai-codex` 渠道认证声明 `chatgpt_subscription_active_start`，同时要求订阅结束日期有效、尚未失效且令牌未过期。这些字段不是稳定公开契约；**当前 Pi OAuth 实现不保留返回的 `id_token`，宿主提供的 access token 没有日期时就会回退**。认证由宿主解析，扩展不自行刷新令牌、不读取其他 CLI 的认证文件、不改写 Pi 登录流程。订阅起点采用服务端原值，不承诺每月续费时重置，也不将登录日、令牌签发时间或额度重置时间冒充订阅起点。

订阅失效、认证不可得或日期缺失时，分别查询滚动最近 7 天、固定 30 天，不按日历月换算。两项是独立区间，不相加。Codex 订阅只确定时间，不要求与被统计 Key 属于同一个 ChatGPT 账号。

费用来自官方 `GET /v1/organization/costs`，始终按单个 `api_key_ids[]` 筛选并按 `api_key_id` 分组，读取完整分页；返回其他 Key 或未归属费用时拒绝汇总。金额为 USD，允许负数费用调整；统计该 Key 在所有客户端已入账的 API 使用费用，不是本机估算、Codex 消耗、账户余额或扣除赠送额度后的现金实付。服务端按日聚合且可能延迟，不承诺精确到秒或实时结算。

Admin Key 只发送到固定的官方 HTTPS 项目、Key 元数据和费用接口，禁止重定向，不发送给 Codex 或模型代理。不输出密钥、原始响应正文或底层认证异常。单次请求超时 10 秒，整个查询使用 60 秒期限信号。不在非交互子代理中自动查询。

**环境更新注意**：已启动的 Pi 不会继承后来在 Shell 中新增的环境变量，`/reload` 也不会重新加载 Shell 配置。新增 `OPENAI_ADMIN_KEY` 后应从已加载该变量的新终端重新启动 Pi；扩展不自行启动登录 Shell。

接口依据：[Costs API](https://developers.openai.com/api/reference/resources/admin/subresources/organization/subresources/usage/methods/costs/)。本地解析和 SDK 测试不替代真实账户请求及终端显示验证。

### 统计口径

从首次 `agent_start` 计时，到 `agent_settled` 结束，期间连续的低层运行不重复计时。工具次数按唯一 `toolCallId` 统计，包含宿主报告的嵌套调用。`turn` 累计本次运行的原生 `turn_start` 事件，自动重试或后续低层运行不会清零；它不是用户消息数，也不汇总子代理内部轮次。token 用量取当前运行新增的原生用量，包括输入、输出、缓存读取和缓存写入；不是上下文占用，也不是订阅账单。

运行摘要显示为 `tools:8 token:126K turn:4 done:32s`，开始运行前不显示，结束后保留最近一次结果。token 按原生 Pi 的数量级格式压缩，单位使用 `K/M`，不足 1000 时显示整数；`/stats` 分项仍保留精确数值。

不写统计文件、会话统计条目或提醒。重载、切换会话、导航到其他分支后清空；不会恢复或修改旧统计记录。

### 目录切换边界

`/cd` 等待当前运行空闲，在目标目录创建新的 Pi 会话文件，通过 `switchSession()` 切换，再更新进程目录。源会话不被覆盖，完整历史仍保留；若当前选择不是磁盘最后分支，使用一条不进入模型上下文的 `custom` 元数据保留分支选择。

普通新会话尚未落盘时也可切换；显式 `--no-session` 会话不支持 `/cd`，避免擅自启用持久化。切换取消会删除本次创建的目标会话文件；切换抛错时保留可能已经生效的目标文件并由 Pi 报错。

扩展不注入、改写或删减 prompt、历史消息、工具参数和工具结果，也不自动发送消息或调用生成模型。显式 `/cd` 会触发 **Pi 原生**目标目录资源与信任检查；目标目录规则可能因此改变，这是目录切换本身的效果。

## 加载

需要 Node.js 22.19+ 和 Pi 1.4.x。开发环境安装依赖：

```bash
npm install --ignore-scripts
pi --no-extensions -e ./utils/index.ts
```

其中 `pi` 命令启动单独实例，不是全局安装。持久安装、卸载其它扩展需要另行操作。不要同时加载另一个底栏所有者，例如 `pi-powerline-footer` 或接管 footer 的旧 `model-quota`，也不要重复加载本包的内部模块。
